# EasyImageSplitter

Нативное macOS-приложение, которое делит фото на равные части для карусели в одном посте: листаешь — и части складываются в цельную картину.

- Любые форматы, которые понимает macOS: JPG, PNG, HEIC, WEBP и др.
- Сразу несколько фото: drag & drop или «Выбрать фото» (⌘O).
- Сетка столбцы × строки (по умолчанию 3 × 1), общая для всех фото. Части нумеруются слева направо, сверху вниз.
- Деление без искажений: остаток пикселей обрезается поровну с двух краёв.
- Экспорт в PNG в исходном качестве: `IMG_1234_01.png`, `IMG_1234_02.png`… Если имена заняты — `IMG_1234-2_01.png`, ничего не перезаписывается.

## Сборка

macOS 14+, Xcode 16+, без сторонних зависимостей.

Откройте `EasyImageSplitter.xcodeproj` и нажмите ⌘R.

## Структура

- `EasyImageSplitter/Core` — логика без UI: `GridSplitter` (сетка), `ImageLoader` (чтение и поворот по EXIF), `TileExporter` (нарезка и имена файлов).
- `EasyImageSplitter/UI` — интерфейс на SwiftUI.
